📋 План разработки проекта Velojol Календарь

Описание проекта

Разработать страницу "Календарь" на сайте Velojol для отображения велособытий: заездов, фестивалей, митапов и других мероприятий.

🔹 Пользователи смогут:

Смотреть события по датам.

Фильтровать события по городам и типам.

Добавлять свои события через модальную форму.

🔹 События проходят модерацию перед публикацией.

Основные задачи

1. Структура данных

Создать файл events.json для хранения списка событий.

Структура одного события:

{
  "id": "event001",
  "title": "Весенний велопробег",
  "description": "Заезд для всех желающих.",
  "datetime": "2025-05-01T10:00",
  "city": "Алматы",
  "type": "Велозаезд",
  "link": "https://example.com",
  "route_link": "https://www.komoot.com/tour/123456",
  "organizer": "Almaty Cycling Community",
  "cover_image": "/static/img/calendar/event001.jpg",
  "status": "pending",
  "created_at": "2025-04-27T10:00:00"
}

2. Backend: Flask

Создать роут /calendar для отображения страницы календаря.

Загрузить данные из events.json и передать в шаблон.

Реализовать POST-роут /calendar/submit для добавления заявок.

Сохранять новые события со статусом pending.

3. Frontend: HTML + JS

Создать calendar.html.

Реализовать сетку дней месяца.

Отмечать даты с событиями.

Клик на дату — открытие попапа с списком событий.

Реализовать фильтры:

По городам.

По типам событий.

4. Форма добавления события

Модальное окно.

Отправка формы через fetch.

Валидация обязательных полей.

5. Админка

Добавить раздел "События".

Отображение:

Ожидающие (статус pending).

Одобренные (статус approved).

Действия:

Одобрить.

Удалить.

Структура проекта

/app
    /static
        /js
            calendar.js
        /img
            /calendar
                (картинки событий)
    /templates
        calendar.html
    /routes
        calendar.py
/static/data
    events.json
